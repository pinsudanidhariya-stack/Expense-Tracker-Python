# Expense Tracker (Python)

A simple command-line Expense Tracker built using Python.

## Features

- Add new expenses
- View all expenses
- Calculate total spending
- Menu-driven interface

## Technologies Used

- Python
- List
- Dictionary
- Loops
- Conditional Statements

## How to Run

```bash
python Expense_tracker.py
```
